# Inter

Unmodified WOFF2 files from `@fontsource/inter@5.2.8`:
https://registry.npmjs.org/@fontsource/inter/-/inter-5.2.8.tgz

Upstream: https://github.com/rsms/inter
License: OFL-1.1 (see LICENSE).

Regular and italic weights 400, 500, 600 and 700; Unicode subsets load only
when needed. inter.css preserves Fontsource unicode ranges and removes WOFF
fallbacks. No external font requests are made at runtime.
